# Documentation Maintenance & Disclosure Policy

This documentation site is maintained alongside the Extra Scoop monorepo. Any pull request that alters user-facing workflows, commercial boundaries, or public API/webhook contracts must update the corresponding documentation in `/extrascoop_docs/` prior to merge. Before merging any documentation changes, the designated Lead Technical Writer or Security Lead must personally re-apply the Disclosure Rule test to every modified sentence, ensuring that internal scoring formulas, model parameters, decision thresholds, vendor subnets, database schemas, and private infrastructure details remain strictly abstracted. Automated pattern scans serve as baseline regression checks, but human review of adversarial mechanisms is mandatory for every commit.
